
# 🌐 geogradev

### Geospatial analysis, mapping, and Python tools for exploring our world.

**geogradev** is an open-source Python project for geospatial analysis, mapping, and spatial data exploration.

It brings together geography, geomatics, programming, and open-source technologies to explore geographic data and develop practical GIS workflows.

From interactive mapping to spatial data processing, geogradev is a space for developing, testing, documenting, and sharing geospatial tools and applications.

## 🚀 Getting started

Install geogradev from PyPI:

```bash
pip install geogradev
```

Import the package into your Python environment:

```python
import geogradev

print(geogradev.__version__)
```

For installation requirements, dependencies, and additional instructions, see the installation guide.

[Installation guide](installation/){ .md-button .md-button--primary }
[Usage guide](usage/){ .md-button }

!!! note "Dependencies and external services"
    Some geospatial workflows may require additional Python dependencies, datasets, or external services. Check the installation guide and the requirements of each module before running the examples.

## 👩🏽‍💻 About the project

geogradev is an ongoing open-source learning and development project created by **Mercedes Aguirre**, a geographer interested in the intersection of geography, programming, and geospatial technologies.

The project reflects an interest in developing accessible and reusable tools for geographic analysis, environmental applications, and territorial research.

As the project evolves, its functionality, documentation, and examples will continue to improve.
